# Canvas de Citas 1.3.0

Tablas en el lienzo.

## Descargas

| Archivo | Para qué |
|---|---|
| `CanvasDeCitas-Android-v1.3.0.apk` | **Celular Android.** Se instala encima de la 1.2.x, sin perder nada. |
| `CanvasDeCitas-web-v1.3.0.zip` | La app web (lo mismo que https://1xmanmax.github.io/canvas-de-citas/). |
| `SHA256SUMS.txt` | Huellas para comprobar que los archivos no se alteraron. |

La app de Windows no cambia de instalador: carga la app publicada y ya trae las tablas.

## Qué trae

- **Tablas** como tarjetas del lienzo general, de cada objetivo y de cada lienzo de lectura (con chincheta, etiquetas,
  conexiones y agrupadores, igual que las notas).
- **Crearlas ahí mismo**: botón de tabla en la barra; se escribe en las celdas, se agregan o quitan filas y columnas y
  la primera fila puede ir como encabezado.
- **Pegarlas del portapapeles**: Ctrl+V en el lienzo con celdas copiadas de Excel, Word, Google Sheets, una página web
  o una tabla en Markdown crea la tabla directamente. En el editor, "Pegar tabla" la trae, y pegar varias celdas dentro
  de una celda las reparte (la tabla crece sola). "Copiar" la lleva de vuelta a Excel o Word.
- El buscador (Ctrl+F) encuentra el texto de las celdas, y Claude Code (skill) las lee y puede crearlas.
