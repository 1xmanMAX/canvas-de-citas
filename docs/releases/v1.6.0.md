# Canvas de Citas 1.6.0

Letras para personalizar cada espacio del lienzo.

## Descargas

| Archivo | Para qué |
|---|---|
| `CanvasDeCitas-Android-v1.6.0.apk` | **Celular Android.** Se instala encima de la anterior, sin perder nada. |
| `CanvasDeCitas-web-v1.6.0.zip` | La app web (lo mismo que https://1xmanmax.github.io/canvas-de-citas/). |
| `SHA256SUMS.txt` | Huellas para comprobar que los archivos no se alteraron. |

La app de Windows no cambia de instalador (sigue la 1.5.0): carga la app publicada y ya trae las letras.

## Qué trae

- **13 letras**: Normal, Serif, Máquina, Manuscrita y las nuevas Libro, Moderna, Elegante, Redonda, Plumón, Escolar,
  Antigua, Código y Lapicero. Vienen dentro de la app: funcionan sin internet y en el celular.
- **En todas partes donde escribes**: cada nota, lista de tareas, tabla, nota de voz (su transcripción), imagen (título y
  texto) y agrupador puede tener su propia letra. En cada editor hay un selector "Letra" que muestra cada opción escrita
  con su letra; "Original" deja el estilo de siempre.
- La tabla también se ve con su letra mientras la editas, y el lienzo mide el texto con la letra elegida para que nada
  se corte ni se encime.
