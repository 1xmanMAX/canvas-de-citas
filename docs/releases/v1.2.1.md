# Canvas de Citas 1.2.1

Arreglo para el celular.

## Descargas

| Archivo | Para qué |
|---|---|
| `CanvasDeCitas-Android-v1.2.1.apk` | **Celular Android.** Se instala encima de la 1.2.0, sin perder nada. (Si aún tienes una versión anterior a la 1.2.0, desinstálala una vez antes: sincroniza primero con la PC.) |
| `CanvasDeCitas-web-v1.2.1.zip` | La app web (lo mismo que https://1xmanmax.github.io/canvas-de-citas/). |
| `SHA256SUMS.txt` | Huellas para comprobar que los archivos no se alteraron. |

La app de Windows no cambia de instalador: carga la app publicada y ya tiene este arreglo.

## Qué trae

- En el celular, la barra de arriba ya no tapa ni corta botones (Configuración, abrir archivo…) en el lienzo,
  la biblioteca y la lista de proyectos. En el lienzo la búsqueda ocupa el espacio libre; en la biblioteca,
  "Exportar .bib" pasó al panel de filtros.
